# Living paper for Modal thought

This project is built as a living paper. That means:

- the site is not a final static document;
- it is a current statement about the evidence and how it is interpreted;
- it will be updated over time as new analyses, data, and insights arrive.

## Why living paper?

Academic research is often published once and then left unchanged. In contrast, `Modal thought` is intended to track the author's evolving view of the evidence. Each version is a snapshot of the current thinking.

## What to expect

- versioned releases with a date and summary
- explanations of what changed in each update
- interactive data exploration instead of static charts
- links between the evidence and the analysis code
