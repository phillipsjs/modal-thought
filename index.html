Academic research platform for sharing data, code, and narrative together through GitHub Pages.

Use this repository as the starting point for a research website, with a structure designed for transparency and reproducibility.

Project overview

This site is intentionally simple so the research content is easy to add and maintain. The first version is a static GitHub Pages site, with the goal of later adding interactive charts, notebooks, and detailed documentation.

Core directories:

  • data/ — raw and processed datasets
  • code/ — analysis scripts and reproducible code
  • text/ — manuscripts, methods, and notes

Data

Store CSV, JSON, and other data artifacts here. Keep data provenance clear and versioned so readers can follow the research pipeline.

Code

Place analysis scripts, notebooks, and reproducible code here. Comment your files frequently so collaborators can understand each step.

Text

Use this folder for manuscript drafts, summaries, and explanations of the research design and findings.

How to use this repo

  1. Add your research artifacts to the `data/`, `code/`, and `text/` folders.
  2. Update this landing page and add new pages as needed.
  3. Create a GitHub repository, enable Pages, and publish from the `main` branch.
