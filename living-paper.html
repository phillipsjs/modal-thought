Living Paper

Modal thought is a living paper

Rather than publishing a fixed report, this project is designed to evolve. The site is a current view of the evidence on modal thought, and it will be updated as new analyses, data, and interpretations become available.

← Back to home · Open navigation

What makes this project living?

  • Versioned updates: content will be tagged with version information and timestamps.
  • Current best view: the site reflects the author’s current interpretation of the evidence.
  • Interactive exploration: data is not just shown, it is explorable and reusable.
  • Transparent workflow: data, code, and text are kept in the repository and linked clearly.

Interactive direction

This project will move beyond static figures. The goal is to let readers:

  • filter datasets by conditions or measures
  • compare evidence across experimental conditions
  • see the code that generated each result

Next, we can add an interactive explorer page that renders charts and tables from live data files.

Repository structure for a living paper

data/

Data files and summaries used to generate evidence.

code/

Analysis scripts, reproducible workflows, and visualization code.

text/

Narrative content, methods, commentary, and living-paper discussion.

version.json

Metadata for the current living-paper release.
